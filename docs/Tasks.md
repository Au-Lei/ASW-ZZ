# 港捷物流业务联系单生成系统——任务清单

## 0. 项目初始化

- [x] 创建最小 Python 项目目录骨架。
- [x] 添加 `app`、`nodes`、`tools` 和 `tests` 包标识。
- [x] 添加 `.gitignore`、不含密钥的 `.env.example` 和依赖占位文件。
- [x] 编写 PRD、架构设计和任务清单。
- [ ] 评审并确认 PRD 的 MVP 边界和角色。
- [ ] 确认代码规范、Python 版本、测试工具和持续集成方案。
- [ ] 在技术选型完成后更新 `requirements.txt`，锁定并审查最小依赖。

## 1. 样本与业务规则

- [ ] 获取首个标准样例对应的脱敏原始文件及使用授权。
- [ ] 收集第一批船公司、文件类型和版式的代表性脱敏样本。
- [ ] 建立样本清单、期望字段、异常说明和黄金答案评审流程。
- [ ] 确认提单号与 Booking No. 的字段关系。
- [ ] 确认日期缺少年份时允许使用的上下文及展示格式。
- [ ] 确认船名、航次、箱型和港口的标准格式。
- [ ] 确认船公司、箱型、港口、场站字典来源与维护责任人。
- [ ] 确认 `QD` 等内部港口简称与标准编码的映射策略。

## 2. 文件接入与解析

- [ ] 明确支持的 PDF、图片和办公文档格式、大小及页数限制。
- [ ] 定义上传文件元数据、摘要、重复提示和安全文件名规则。
- [ ] 实现文件类型校验、损坏/加密文档识别和安全限制。
- [ ] 实现文本型 PDF/文档的文字与版面信息提取。
- [ ] 实现扫描页识别和按需 OCR 分流。
- [ ] 保留页码、区域或原文片段等可复核证据。
- [ ] 为不支持、损坏、超限和解析失败文件提供明确错误状态。

## 3. OCR 与 AI 提取

- [ ] 确认数据合规、成本和部署约束，评估候选 OCR/AI 服务。
- [ ] 定义 OCR 适配接口、输出结构和错误分类。
- [ ] 定义 AI 提取 Schema、字段说明、候选值和证据引用格式。
- [ ] 编写并版本化提示词，明确空值、冲突和禁止猜测规则。
- [ ] 实现 AI 适配接口及严格 Schema 校验。
- [ ] 记录服务、模型、参数、提示词版本和追踪信息。
- [ ] 设计有限重试、超时、降级和转人工策略。
- [ ] 使用脱敏样本评估各字段提取质量和 OCR 使用率。

## 4. 标准化与校验

- [ ] 定义字段级结果结构：来源、原始值、标准化值、置信度、候选、异常和人工状态。
- [ ] 建立船公司别名与标准值映射。
- [ ] 建立箱型别名与结构化表示映射。
- [ ] 建立港口别名、内部简称及标准编码映射。
- [ ] 建立场站别名与标准名称映射。
- [ ] 实现仅对唯一有效映射自动标准化的规则。
- [ ] 实现日期标准化，并阻止无可靠上下文的年份猜测。
- [ ] 实现编号按字符串保存及提单号/合约号候选冲突提示。
- [ ] 实现船名、航次空白及格式规则。
- [ ] 实现箱量及类型解析，同时保留原始展示值。
- [ ] 实现缺失、低置信度、多候选、跨页不一致和未映射提示。
- [ ] 版本化并审计规则与映射变更。

## 5. 人工复核

- [ ] 确认复核界面形态、用户角色和权限边界。
- [ ] 设计原文件/页图与字段证据对照视图。
- [ ] 展示原始值、标准化建议、置信度、候选与异常原因。
- [ ] 支持接受、修改、明确留空和退回重处理。
- [ ] 记录修改前后值、操作人、时间和确认状态。
- [ ] 生成前汇总未解决项并要求明确确认。
- [ ] 确认是否需要双人复核、重新打开和版本留存。

## 6. Excel 生成

- [ ] 获取并由业务确认正式“港捷物流业务联系单”模板。
- [ ] 确认字段到工作表/单元格的映射、展示格式和空值表现。
- [ ] 确认纸型、方向、页边距、打印区域、页眉页脚和目标 Excel 版本。
- [ ] 选择并验证最小 Excel 处理依赖。
- [ ] 实现模板版本管理和字段映射配置。
- [ ] 仅将人工确认后的最终值写入模板副本。
- [ ] 保留公式、样式、合并区域和打印设置。
- [ ] 实现安全文件名、防覆盖策略和输出摘要。
- [ ] 校验生成文件可打开、关键字段落位并可编辑打印。

## 7. 存储、安全与运维

- [ ] 确认部署环境、数据驻留、网络和第三方服务限制。
- [ ] 确认数据库、文件存储、任务执行和备份方案。
- [ ] 定义原文件、结果、审计与日志的保留及删除策略。
- [ ] 实现密钥管理；确保仓库、日志和输出不含密钥。
- [ ] 实现身份认证、最小权限和文件访问审计。
- [ ] 对解析、OCR 和 AI 调用设置隔离、超时及资源限制。
- [ ] 建立任务阶段、耗时、错误、版本和人工修改率指标。
- [ ] 配置告警阈值、故障排查信息和运维责任人。

## 8. 测试与质量

- [ ] 为日期、编号、箱型、别名映射和冲突规则编写单元测试。
- [ ] 为 OCR/AI 适配器编写契约测试和失败分支测试。
- [ ] 为“上传到待复核”及“确认到 Excel”编写集成测试。
- [ ] 为 Excel 关键单元格、版式与打印设置建立回归测试。
- [ ] 建立按船公司和格式分类的脱敏黄金样本回归集。
- [ ] 验证损坏、加密、伪造类型、超限和恶意文档处理。
- [ ] 验证日志、测试夹具和错误信息无敏感数据泄露。
- [ ] 定义字段级准确率、人工修改率和失败率的验收阈值。

## 9. 试运行与上线准备

- [ ] 选定有限用户、船公司和样本范围进行人工并行试运行。

- [ ] 评审处理时延、调用成本、人工节省时间和可用性。
- [ ] 完成安全、合规、备份恢复和故障演练评审。
- [ ] 形成上线、回滚、支持和培训方案。

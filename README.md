# ASW-Project01

国际海运货运代理内部应用，用于将船公司入货通知中的业务信息转换为可人工复核的数据，并最终生成可编辑、可打印的 Excel“港捷物流业务联系单”。

## 当前阶段

项目处于初始化与方案定义阶段。第一阶段聚焦“入货通知识别 → 字段标准化 → 人工复核 → Excel 生成”，当前仓库仅包含目录骨架和设计文档，尚未实现任何业务功能。

## 目录说明

- `app/`：未来的应用编排、状态定义、处理节点与工具适配层。
- `prompts/`：未来的 AI 提取提示词及版本说明。
- `tests/`：未来的单元测试、集成测试和脱敏样本测试。
- `docs/`：产品、架构和实施任务文档。
- `.env.example`：未来环境变量名称与说明的示例，不含真实密钥。
- `requirements.txt`：依赖清单；技术选择明确前不引入依赖。
